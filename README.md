# Rule Engine in C++ — Автономний шлюз автоматизації на ESP8266

Повноцінний автономний шлюз автоматизації на базі мікроконтролера **ESP8266 (Wemos D1 mini)** із вбудованим веб-інтерфейсом (SPA), неблокуючим опитуванням датчиків та динамічним **конструктором правил (Rule Engine)**, що дозволяє керувати логікою пристрою «на льоту» через браузер без перепрошивки.

---

## 🚀 Основні особливості

* **State-Machine Wi-Fi Архітектура:** Стабільне підключення до мережі без блокування та ризику спрацьовування сторожового таймера (WDT resets).
* **Динамічний Rule Engine:** Можливість створювати, видаляти та зберігати правила автоматизації прямо у вебмобільному інтерфейсі (наприклад, *«Якщо відстань < 20 см, то діяти»*).
* **LittleFS файлова система:** Швидка роздача сучасного SPA-інтерфейсу (`index.html`, `style.css`, `app.js`) безпосередньо з Flash-пам'яті ESP8266.
* **Неблокуюче опитування датчиків:** Інтеграція ультразвукового датчика **HC-SR04** за допомогою таймерів `millis()`.
* **REST API (JSON):** Двосторонній обмін телеметрією та правилами за допомогою бібліотеки `ArduinoJson`.
* **SPA Fallback:** Автоматична маршрутизація для коректної роботи односторінкового застосунку.

---

## 🛠 Апаратне підключення

| Компонент | Пін датчика / модуля | Пін Wemos D1 mini | Пін ESP8266 GPIO | Примітка |
| :--- | :--- | :--- | :--- | :--- |
| **HC-SR04** | VCC | 5V (або 3.3V) | - | Рекомендовано 5V для стабільності |
| **HC-SR04** | GND | GND | - | Загальна земля |
| **HC-SR04** | Trig | D5 | GPIO 14 | Вихід тригера |
| **HC-SR04** | Echo | D6 | GPIO 12 | Вхід відлуння (бажано через подільник напруги) |
